# 第一阶段实现与验证记录

范围：生成性能、资料增强、教师风格、学科策略、BOPPPS、学科组件、课堂配图（原计划 1、2、3、4、5、13、18）。不修改项目说明书。

## 已实现

- 首屏选择教学模型和风格，配置贯穿大纲、课件及教案；后台发布学科方法、活动、视觉、页面结构和示例提示。
- 独立预处理并发、快速档减少模板上下文和模型修复调用，返回首张和总耗时指标。
- 临时资料上传、优先检索引用、转存个人资源库、按会话清理与到期清理。
- 教师画像启停、标签、历史反馈重学、历史文件语义风格分析；显式保存记录编辑指标，重复信号学习、每日按需刷新。
- BOPPPS 大纲阶段检查，教案六阶段补齐、课时守恒及真实页码映射。
- 公式、化学式、流程图、图表、表格与多项式函数坐标图 DSL；预览与保存使用统一渲染器，双组件上下排布。
- 自动配图与单页生图、保存资源库、教师月度 Redis 原子配额、缓存命中免计费、调用失败尝试退额与占位降级。

## 验证命令

从 `backend-python/A12-PY` 执行：`.venv/Scripts/python.exe -m pytest -q`。

从 `backend-java/A12` 执行：`mvn test -q`。

从 `frontend` 执行：`node --test tests/subjectTool.test.mjs`，以及 `npm run build`。

从 `frontend-admin` 执行：`npm run build`。

Python 新增集成回归通过真实前端组件渲染器生成公式、化学式及坐标图 HTML，再用 Chromium DOM→PPTX 导出并检查标题为可编辑文字、媒体已嵌入。需要安装前端依赖、Node 和 Chromium；缺少依赖时测试明确跳过，不能算导出验收通过。

本轮（2026-10-07）验证结果：Python 全量 102 项通过，无跳过；Java 49 项通过，无失败或跳过；前端学科组件渲染回归通过；教师端与管理端生产构建通过；`git diff --check` 通过。生产构建仍有大包体积及既有导入告警，Python 有依赖弃用告警，不影响本轮构建测试，但不代表没有后续优化空间。

## 验收边界

- 构建和自动化回归通过不代表外部服务已经联调。当前还需实际登录、OSS 上传、Redis 配额及真实文生图联调。
- 复杂公式、SVG 和图示允许局部栅格化，不承诺内部图元均能在 PowerPoint 原生编辑。
- 函数图像当前支持至多五次的多项式，不支持任意可执行函数表达式。
- 风格刷新是生成前按需执行，不是教师离线时持续运行的后台定时训练。
- 单份历史材料仅作为参考，不证明教师长期稳定偏好；手动要求可覆盖，画像可禁用。
- 性能测量受模型服务、页数、网络和模型档位影响，不能将单次样本当作固定耗时保证。
