# 第二阶段：图谱驱动教学内容

分支：`feature/graph-driven-learning`，从本地 `main` 迁出。

## 实现范围

- 课程双图谱工作台：资料增强提取知识和技能候选，教师确认后保存；节点属性、关联个人资料、关系和拖动布局可编辑。
- 图谱版本：按用户隔离保存，版本快照、乐观锁冲突检查、历史版本恢复为新版本。
- 学习路径：目标知识选择、先修闭包、已掌握节点排除、拓扑排序和人工调整校验；重复关系、自环和先修环路拒绝保存。
- 图谱驱动课件：按学习路径逐节点安排页面，保留知识/技能节点溯源信息；支持资料增强、可编辑 PPTX 导出及保存到原有编辑工作台。
- 检索剪枝：固定层级扩展，难度和考频排序，节点数与估算 Token 预算限制；展示剪枝前后指标，不冒充模型供应商实际计费数据。
- 学习视频：HTML 静态画面与语音旁白合成 MP4；持久化任务、进度、取消、有限重试、任务租约及过期清理；导出中心下载或主动转存资源库。

## 验证口径与边界

本轮执行结果：Python 全量测试119项通过（包含 PostgreSQL 集成测试与视频编码测试）；前端 `node --test tests/course-workspace.test.mjs` 9项回归测试通过；教师端 `npm run build` 通过；`git diff --check` 无空白错误。尚未进行真实登录页面与外部模型、语音服务的端到端联调。

提交前复查修复：视频允许26页，覆盖24个知识节点加封面、总结；执行期间锁定表单与关系删除，停止按钮保持可用；切换目标、起点、已掌握节点、学科或年级立即清空旧路径及生成结果，但不误标记图谱未保存；销毁页面后拒绝迟到的流式结果；文档认知层级字段统一为 `bloom`。

- PostgreSQL 集成测试覆盖版本冲突、历史快照、任务配额、取消、租约与有限重试；测试使用独立随机用户并清理自身数据。
- 视频编码测试使用真实 Chromium 和 FFmpeg，语音响应使用测试替身。因此不等同于外部 TTS 服务已联调成功。
- 视频为静态幻灯片加旁白，不是动画录屏。为避免 HTML 外部访问，渲染阻断网络与脚本；请使用内联样式和内嵌图片。
- 默认每用户最多三个活动视频任务，每个任务最多两次执行；最多26页（24个路径节点加封面、总结），成品本地保留24小时。资源库转存由教师主动点击，不自动上传 OSS。
- TTS 服务必须支持兼容 OpenAI Speech 的接口；可以独立配置 `TTS_API_KEY`、`TTS_BASE_URL`、`TTS_MODEL` 和 `TTS_VOICE`。
- 图谱剪枝降低上下文预算，不构成生成质量提升的实验结论；真实模型耗时、计费及教学效果仍需在线对照评估。
- AI 请求仍由前端直连 Python；Java 保留项目和资源等业务接口。
