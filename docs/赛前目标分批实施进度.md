## 第 4 批：教学计划与 Word 章节批量生成

第 5、6 项已共用同一链路实现，完成真实模型与 Java—Python 接口联调。

- 新增批量生成意图，识别整门课、整本教材、教学计划等请求。
- Word 按标题样式、编号和字号提取章节，正文、表格和图片按位置归章。
- 对话显示章节与拆分计划卡，可选择范围、份数，修改后统一确认。
- 缺少教材版本或章节依据时先补充，不把推测目录当作确定教材目录。
- 持久化批次与单项任务，支持配额、进度聚合、失败单项重试和中断恢复。
- 每章生成独立项目，沿用现有 HTML、主题、工作台和 PPTX 导出。
- 产物支持批量 ZIP 下载，单份转换作为 N=1 的统一流程。
- 解析结果和原始文件关联保留，识别不足时提示教师补充结构。

使用入口：AI 教学助手输入“按这份教学计划逐章生成 PPT”，或从已有 Word 转换入口选择按章/单份转换。对话先展示批量备课计划卡；教师核对学科、年级、教材版本、章节、课时、教学要求、页数范围和主题后，一次确认提交。教师也可以粘贴或口述包含多章的计划，通过对话让 AI 调整拆分；只有书名时先补充目录，或明确选择接受 AI 建议目录，不把建议冒充真实教材目录。

Word 按标题 1/2/3、章节编号及字号启发式构建树，保留正文、表格和可提取插图。明确标注的课时与教学目标进入计划卡；其他格式可由教师或 AI 补充。没有可靠标题时降级单份讲义并提示补充结构，原始 Word 可下载查看。单份转换与按章生成使用同一条管线。当前支持 .docx，不支持旧版 .doc 二进制文件。

批量任务面板：AI 教学助手首屏 → 批量备课任务，也可从计划卡进入。每批最多 24 份、240 页，每份 1–30 页；全局最多两个章节同时执行，同一教师同时执行一章。批量默认轻度推理，可改标准/深度，始终使用项目默认模型，不改变模型超时和 SDK 重试预算。页面仍由现有完整 HTML 管线生成，沿用主题、配图、教师画像与工作台。

批次、单项和逐页检查点保存到 PostgreSQL。单项失败可手动重试，最多三次实际执行；配额等待不计为失败次数。服务重启后回收超时租约，合格且与当前标题、提示版本匹配的页面可复用。取消会中止执行中的异步模型调用，后台调度器继续处理其他任务。数据库续租失败时停止本次生成，避免旧执行者继续输出重复产物。

每章完成后通过 Java 的幂等业务接口建立独立个人项目，并保存初始快照；重复同步返回同一项目，不覆盖教师后续编辑。Java 与 Python 配置相同 A12_PYTHON_INTERNAL_KEY 时支持关闭网页后自动归档；未配置密钥时产物保存在 Python，教师重新进入页面可使用登录态同步。首页同步有数量与等待上限，管理端不可用时停止本轮扫描；任务面板连续三次同步失败后保留手动同步按钮。

整批 PPTX/ZIP 复用现有浏览器 DOM 导出管线；可只打包已完成章节，清单标注失败与取消项。ZIP 采用本次批量生成的初始版本，工作台后续修改应从项目或导出中心导出最新版本。
