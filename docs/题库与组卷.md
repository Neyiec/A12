# 题库与组卷

教师端进入“题库与组卷”，默认展示公共题库。后台进入“题库录入与审核”。

## 使用流程

1. 按学科、年级、题型、难度或题干/知识点搜索；点击“查看答案与解析”核查内容。
2. 点击“加入题篮”，再点击右上角“组卷”进入全屏工作台；也可以直接进入组卷，再在右侧“题库选题”添加题目。
3. 保存后，在“我的试卷”中重新打开。预览可以切换学生作答版与答案解析版，打印窗口选择“另存为 PDF”。
4. “设计题目”可保存草稿或提交审核。“我的投稿”可查看状态和审核意见；退回后可编辑重投。审核中/已公开题目不可直接改写，可复制改编后重新投稿。
5. 后台人工检查准确性、答案解析、难度学段、内容规范，通过后公开；退回/下架必须给出原因。后台录入完整题目后可以直接发布。

支持单选、多选、判断、填空、简答、计算/综合题，复用数学公式和化学式编辑组件。题干/选项以纯文本安全显示，公式由禁用 trust 的 KaTeX 渲染；不接受任意 HTML。

## 数据与部署

Java 负责题库、审核、试卷与权限，未增加 Java 转发 Python 的 AI 请求。
Java 启动时执行幂等的 `src/main/resources/db/question_bank.sql`，只创建缺失的三张表，不删改已有业务数据。
数据库账号需要建表权限；不授予建表权限的生产环境请先由 DBA 执行同一个 SQL 文件。
题目审核复用现有 RBAC：查看 `audit:view`、审核/下架 `audit:audit`、后台录入 `resources:edit`。

试卷只允许本人访问。保存时从服务端读取题目并固化快照，不信任客户端传入的答案；编辑已保存试卷保留已有快照。新加入题目须为已公开题目或本人完整草稿。单份限 100 题、同一学科、每题 0.01–100 分；通过 revision 防止并发覆盖。题目审核记录单独保留。

当前是人工审核、手动选题与浏览器打印/PDF，不宣称已实现 AI 出题、自动批阅或 Word 导出。

## 组卷工作台

页面默认进入公共题库，右上角固定提供“组卷”入口并标注题篮数量。组卷界面参考课件工作台采用蓝白配色：左侧题目目录支持定位、上移、下移和移除；中间按实际题序预览整份试卷，可切换答案；右侧设置试卷名称、考试时间与每题分值，或切换到题库选题。第一题加入后，题库查询自动限定该学科，防止混入其他学科。

顶部提供保存、预览与打印。“我的试卷”可重新打开已保存试卷；“新建试卷”主动打开空白工作台，不自动写入数据库。返回题库不会清空当前题篮；离开路由或关闭网页时，对未保存修改给出提醒，包括移除最后一道题的情况。
